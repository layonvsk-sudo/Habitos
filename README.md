# Habitos
Cansado de começar uma nova rotina com empolgação e desistir logo depois? Em "Como ter melhores hábitos", você aprende um método simples para criar hábitos que ficam, com 9 capítulos curtos, tarefas práticas e um plano de 7 dias. Inspirado em Hábitos Atômicos, de James Clear. De brinde, o app Organize seus hábitos. Comece hoje, e faça parte dos 1%!
